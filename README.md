# Gridwise Studio

An original BESS peak-shaving learning studio. It is an educational simulator, not a live energy-management controller.

## Start locally

```bash
npm install
npm run dev
```

## Governance

Read `AGENTS.md`, `PROJECT_CONTEXT.md`, `DECISIONS.md`, `QA_LOG.md`, and `INCIDENT_LOG.md` before changing the project. Work is tracked through GitHub Cases (Issues); only the user closes a case.
